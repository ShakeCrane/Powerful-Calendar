## 1. 设计体系与关键决策

设计先于修改落盘：[设计体系](POWERCAL_GLASS_DESIGN.md)；实际接口约束：[UI 交接契约](GEMINI_UI_HANDOFF.md)。

采用雾白/石墨两个实时系统主题，蓝色闹钟、绿色活动、琥珀色截止；类型文字、图标与颜色共同表达语义。
主卡直立、背卡小角度旋转；玻璃用高不透明度承载面、细边与轻微层次模拟，不使用重阴影或昂贵背景采样。
正文以可读性优先，主题入口补齐全局内容色，避免弹窗在暗色下继承黑色文字/图标。
低内存取消背卡装饰并降低阴影；系统关闭动画时即时切换，设置变化由 ContentObserver 观察。
前台切页/提交串行执行，自动暂存不反复切换输入框只读状态；没有在 UI 重写事务、幂等或全量覆盖规则。

## 3. 设计前后差异

| 基线 | 本轮 |
| --- | --- |
| 顶栏一排横滚按钮并覆盖轴内容 | 头部/独立画布/底部玻璃导航，信息分层，48dp 操作 |
| 固定高活动 chip、日期截止锚在午夜 | 区间活动与独立日期带，初始视角与缩放语义明确 |
| 旧 fling 不可中断、缩放重心混合计算 | 可取消惯性，旧/新重心间保留真实时刻 |
| 重叠卡片相互遮盖、全库一个折叠入口 | 依宽度分轨、每个重叠时间组可展开 |
| 紧凑态也塞满表单，单行操作拥挤 | 摘要→完整编辑，内部滚动；独立页码/操作；极小高度整卡可滚动 |
| 忽略返回时保存失败，正式搜索漏 flush | 离开屏障统一，失败保留输入，显式重试 |
| 授权后重读全队列，范围可能扩张 | 固定已审阅清单和操作；追加卡片不扩权 |
| 冲突少字段、删除文案错误宣称可撤销 | 完整快照审阅，区分删除/替换，只宣称撤销丢弃 |
| 无月历、工具长行容易挤压 | 新月历；工具分区、配置折叠、长文自动换行 |
| 动画偏好只启动时读取，暗色弹窗部分黑字 | 实时偏好与内容色继承；用实际软件图发现并修复问题 |

## 5. 性能与无障碍证据

| 项目 | 证据 | 不能据此得出的结论 |
| --- | --- | --- |
| 100 卡 | 真实 SQLite 建立 100 张；展开、输入最后一字、立即下一张；检验落库、身份和页码；第 100 张未组合 | 未测高速连续操作下的帧率/GC |
| 绘制范围 | 时间轴仅组合可见条目；重复投影按日期窗口记忆；卡组只组合当前编辑器和少数装饰背卡 | all() 仍全库加载，不能宣称无限规模分页 |
| 手势 | 卡内单步、输入区优先、纵向不翻页、卡外多张、缩放/惯性中断的 Compose 合成测试 | 不代表硬件触控采样、120Hz 或 IME 选择手柄 |
| 对比度 | 实际主题 glassFill 合成背景：浅色语义正文最低 5.16:1，深色最低 8.81:1；六类正文色均 ≥4.5:1 | 不包括所有禁用装饰、系统 UI 或每一像素的实机对比度 |
| 触控/语义 | 翻页按钮和日期格部分 48dp 边界断言；按钮描述、标题语义、页码 live region、轴浏览自定义操作 | 不是全页面触控扫描，也不是 TalkBack 真人验收 |
| 设置响应 | ContentObserver 通知模拟，减少动画状态无需重建；深色切换保留同一草稿文本/焦点 | Robolectric 设置通知由测试显式发出；真实系统与输入法仍未测 |
| 视觉 | API 34 native graphics 软件 Canvas，明暗时间轴、摘要/完整卡、月历人工检查 | 不代表真机 GPU、真实背景模糊或动画帧时长 |

**没有 60Hz/120Hz 的 P95/P99、掉帧率或真机性能结论。**
Controller 的同步锁内部仍执行存储 IO，慢设备上 edit 可能等待 flush；没有在 UI 层改造这个领域接口。
