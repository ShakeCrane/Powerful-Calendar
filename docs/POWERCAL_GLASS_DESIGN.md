# PowerCal Glass · 设计系统与交互方案

先于 Compose 修改制定，2026-10-20；接口约束见 GEMINI_UI_HANDOFF.md。

## 视觉语言

浅色为雾白底、墨蓝正文；深色为深石墨底、冷灰正文。闹钟蓝、活动绿、截止琥珀，三种语义跨主题保持一致；同时使用类型文字和图标，不仅靠颜色区分。
8dp 基础节奏，页面边距 16–24dp；主卡 28dp、次级块 20dp、chip 14dp。主卡正文 16sp、辅助 12–14sp；字体放大时允许换行和滚动。
玻璃采用高不透明度分层填充、单条细边、轻微渐变，正文承载面接近不透明。只对背卡用旋转与淡化，主卡不倾斜。不使用假称背景模糊的 RenderEffect，也不增加高成本离屏采样。低内存使用实色面、减少背卡。
标准弹簧采用接近临界阻尼，不循环、不粒子轰炸。系统动画关闭时即时切换；设置变更实时响应。惯性属于直接操控延续，新手势立即打断。

## 中央时间轴

顶部：PowerCal 品牌/可见日期，月历、工具入口。底部玻璃栏：今日、待处理数量、新建；缩放按钮作为双指的无障碍替代。画布从导航之间独立取得高度，初始本地今天 12:00 居中，今日回真实现在；返回卡组与月历保留 camera。
固定中央轴，左闹钟、右活动与截止。中央保留刻度间距；窄屏一条可读轨，宽屏增加轨道。超出的同组显示可点数量，展开清单可逐一进入草稿。
活动用纵向长度表示持续时间，极短活动保留最低触控高度。日期级截止放独立日期带，显示日期及“无具体时刻”，不占用午夜刻度。
双指缩放 4–48h/画布，先以原重心求时间锚点，再将其移动到新重心；手指数变化不平移。单指惯性上下连续跨日；新触摸、今日和缩放按钮中断旧惯性。DST 用瞬间几何，回拨重复小时显示 offset。
长按预览吸附时刻，松手创建修改草稿，确认前不修改正式事件。重复事件拒绝拖动并提示范围编辑待支持。

## 待处理

居中弹窗最大宽度 600dp，左右保留卡外浏览区。摘要卡提供永久序号、提案动作、类型、标题与时间；点击展开完整编辑。1–2 张背卡做有节制的扇形层次。翻页以 draftId 键控，仅动画当前内容，不组合全部 100 张。
卡内横滑一次一张；文字、选择和纵向滚动优先。卡外横滑按距离与速度多张浏览，纵向滑动不退出，边缘不主动抢系统返回。始终提供上一张/下一张可点击替代。
编辑 300ms 暂存；任何离开先 flush，失败留在原卡并显示可重试错误。处理中禁用输入，串行执行 UI 命令。只读 AI 状态允许浏览与返回时间轴，隐藏写操作能力。
紧凑态和完整态都有明确发布/丢弃动作；页码从 1 开始。小高度/横屏/键盘打开时，收起搜索与操作说明，头部只保留身份/退出，编辑区内部滚动。外部点击与系统返回都是保存退出。
冲突以“当前正式版本 / 本卡完整快照”逐字段呈现；重复规则、例外、覆盖、来源和时区全部包含；整份覆盖由 Controller 再校验。正式删除确认不宣称可撤销；丢弃有撤销。
完成页从 Controller 的真实持久化统计驱动：柔和勾号入场、已发布/已丢弃计数、轻暖文案、即时返回和撤销；不强制倒计时，给撤销留出时间。

## 其他页面

月历：月切换、今天、星期标头、选中日期与三类计数；当天日程可打开同一草稿编辑器；空状态可新建。无时刻截止保持日期语义，重复实例来自 RecurrenceEngine。
工具：待处理与授权、自然语言输入、模型配置、导入、备份导出、提醒状态、诊断分区。模型凭据默认遮蔽，配置可折叠；AI 请求明确生成草稿。导入/编辑在独占时禁用，阅读与导出仍可用。
授权：固定 draftId 集合、逐动作数量、清单及删除风险，一次授权一次批次；取消说明已提交保留。进度只显示接口能证明的数字。
提醒：精确闹钟/通知权限各有状态及入口；从系统设置返回后刷新。展示实际期望调度与最近执行记录；旧闹钟交接说明人工关闭原时钟后再启用，避免重复响铃。
