## 重要区分
- 运行 Android 单元测试、Robolectric 或 API35 AVD PASS ≠ 真机 PASS。
- “最近任务划掉”≠“系统设置里强行停止”。后者由系统限制闹钟/后台接收，不能自动当作可修 App Bug。
- REC-P1-068 date-only Deadline 的时间轴锚点与 TalkBack 完整措辞仍待用户正式裁决；别自行标 PASS。
- REC-P1-002 台账旧预期已过时，必须由台账所有者同步最新“今日中午 + 24h”裁决。
- 没有实际完成的项目保留 NOT TESTED/BLOCKED，不因“应该没事”改 PASS。
